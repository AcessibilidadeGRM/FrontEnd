Exercício prático

Fishing Mania: qual é o problema de acessibilidade?

No jogo Fishing Mania, a ação de lançar a isca foi construída com um elemento visualmente clicável, mas sem a semântica necessária. Analise o trecho e escolha a alternativa que identifica o problema principal.

Analise o código incorreto

A interface mostra “Lançar isca” como uma ação, porém o código usa uma div no lugar de um controle interativo.

<div class="botao-pesca" onclick="lancarIsca()">
  Lançar isca
</div>

Importante: o trecho acima é apenas texto para análise. Nenhuma div desta página funciona como botão.

Qual é o principal erro de acessibilidade?

Solução semântica

Use o elemento criado para ações

<button type="button">Lançar isca</button>

Por que essa solução é acessível?

  • O elemento button comunica automaticamente o papel de botão às tecnologias assistivas.
  • Ele entra na ordem de foco sem exigir tabindex adicional.
  • Pode ser acionado pelo teclado com Enter ou Espaço, além do ponteiro e do toque.
  • O texto “Lançar isca” fornece um nome acessível claro para a ação.
  • type="button" evita o envio acidental caso o controle seja usado dentro de um formulário.

Adicionar apenas role="button" a uma div não oferece sozinho o comportamento de teclado, o foco e os estados nativos. Quando a ação é um botão, prefira sempre o elemento button.
